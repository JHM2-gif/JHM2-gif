## Proyectos

### Active Directory + Splunk SIEM Lab

Laboratorio diseñado para simular un pequeño entorno corporativo Windows integrado con monitoreo centralizado de seguridad.

Componentes implementados:

- Windows Server 2022
- Active Directory Domain Services (AD DS)
- Domain Controller
- DNS
- Organizational Units (OUs)
- Windows 10 Pro
- Unión de endpoints al dominio
- Gestión de usuarios y grupos
- Sysmon
- Splunk Universal Forwarder
- Splunk Enterprise
- Windows Event Logs
- Monitoreo centralizado de logs
- Configuración de redes virtuales
- Troubleshooting de red y autenticación
- Kali Linux como estación de ataque

También he realizado simulaciones controladas para generar telemetría de seguridad y posteriormente analizarla desde Splunk.

[Ver proyecto Active Directory + Splunk SIEM](https://github.com/JHM2-gif/active-directory-splunk-siem-lab)

### Windows & Kali Network Lab

Creé una red virtual aislada utilizando VirtualBox para conectar sistemas Windows y Kali Linux.

Durante el laboratorio practiqué:

- Configuración de redes virtuales
- Direccionamiento IP
- Pruebas de conectividad ICMP
- `ping`
- Troubleshooting de red en Windows
- Troubleshooting de red en Linux
- Comunicación interna entre máquinas virtuales

### Splunk Lab

Laboratorio enfocado en aprender los fundamentos de un SIEM utilizando Splunk.

Áreas trabajadas:

- Análisis básico de logs
- Investigación de eventos de seguridad
- Windows Event Logs
- Sysmon
- Flujo básico de investigación en un SIEM

### Python Customer Summary Project

Desarrollé un programa básico en Python para procesar información de ventas de clientes.

El programa calcula:

- Ventas totales
- Promedio de ventas
- Número de transacciones
- Venta máxima
- Venta mínima

También incluye validación básica de entradas y manejo de errores.
